Build DevFlow AI — Full-Stack Developer Collaboration Platform

You are a senior full-stack software engineer, UI/UX designer, AI engineer, database architect, and DevOps engineer.

Build a production-ready full-stack web application called DevFlow AI.

1. Product Vision

DevFlow AI is an AI-powered developer collaboration platform where software teams can manage projects, tasks, documentation, GitHub activity, team communication, and AI assistance from one modern dashboard.

The application must feel like a real SaaS product, not a basic college CRUD project.

Prioritize:

- Clean architecture
- Modern responsive UI
- Secure authentication
- Scalable backend
- Excellent database design
- Real-time functionality
- AI integration
- Production-quality code
- Good developer experience

- "Summarize this project."

- "Explain this project documentation."
- "What should we work on next?"

27. Development Rules

IMPORTANT:

1. Do not build everything in one giant file.
2. Do not use fake APIs when a real implementation is required.
3. Do not hardcode user/project data in production components.
4. Do not expose secrets.
5. Use TypeScript strictly.
6. Use reusable components.
7. Validate all user input.
8. Handle loading, error, and empty states.
9. Make the application responsive.
10. Keep the architecture scalable.
11. Write clean and maintainable code.
12. Explain major architectural decisions in documentation.
